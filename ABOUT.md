# About

This repository collects my GCTF 2026 challenge write-ups, notes, screenshots, and solver scripts.

The write-ups are organized into **Earlier Rounds** and **Finals**. Each challenge folder contains the evidence and steps I preserved while solving it. Original challenge binaries/archives are intentionally not redistributed here.

> `No Loose Ends` is fully documented using a two-stage evidence chain: the PCAP identifies the quarantined artifact and SHA-256, then VirusTotal relations reveal the dropped flag filename for that exact sample hash.
